-- Kierpocalyptic Homestead - sandbox toggles for mod compatibility.
-- Each option follows the pattern "when this third-party mod is loaded
-- AND this toggle is ON, KH defers to the mod for this feature." Off
-- means KH stays active even when the mod is present (player wants both
-- systems, or wants to compare).
-- Default for every defer-to-mod toggle is TRUE, matching Kierstal's
-- compatibility-first preference (see kh-compatibility-first-not-reinvent).

{

	default = true,

}
