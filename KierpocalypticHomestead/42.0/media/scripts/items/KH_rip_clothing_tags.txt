/*
 * Kierpocalyptic Homestead - Rip Clothing tag fix (v0.0.2)
 *
 * B42 item-script overrides REPLACE fields (not merge), so partial overrides
 * that only specify `Tags = ...` will strip every other field and break the
 * item. This file ships the FULL vanilla item body for each target item,
 * with `base:ripclothingcotton` appended to existing Tags (or set as the
 * only Tag if vanilla had none).
 *
 * Also corrects two vanilla typos: `Tshirt_EMD` shipped with
 * `base:ripclothingcoton` (missing n) and `Tshirt_IndieStoneDECAL` with
 * `base:ripclothigcotton` (missing n).
 *
 * Bodies copied from media/scripts/generated/items/clothing.txt with
 * only the Tags line modified.
 */
