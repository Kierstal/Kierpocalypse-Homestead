/*
 * Kierpocalyptic Homestead - fanny pack capacity buff
 *
 * Vanilla fanny packs have Capacity = 1 across all six variants
 * (Front/Back x normal/Hide/Tarp). At weight unit 1, that's roughly one
 * candy bar - so cramped it makes the slot near-useless.
 *
 * This file restates each fanny pack with Capacity = 5. We DO NOT use
 * partial overrides - per the lesson learned with FabricType, B42 silently
 * breaks an item when a script supplies only a single field. Each item
 * body is the complete vanilla definition (as of B42.18 container.txt)
 * with Capacity bumped.
 *
 * If vanilla retunes any of these items (new tag, new sound, new option),
 * we'll lose that change. Re-grep vanilla container.txt for "item Bag_FannyPack"
 * after any major build before assuming this file is still accurate.
 */
